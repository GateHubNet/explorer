# MPT Page and the Token List's MPT Tab (E14) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve `/{net}/mpt/{ID}`, its holders and transfers pages and the MPT tab of `/{net}/tokens` from D9, and show every MPT amount the explorer draws (transactions, account, escrow) in its token's units with a link to its page, behind the new `MPT` switch.

**Architecture:** Task 1 syncs D9's API description and adds the types, shape checks and calls; a seeded generator writes the MPT fixtures. MPT amounts are modelled in `parse/` and `describe/` as integer units with an issuance ID; a loader collects its page's issuance IDs (`mptAmountsOf`), makes one `GET /v2/mpt?ids=` call (`loadMptLookup`), and `resolveMpt` scales them in the Worker. The MPT page's loader reads D9, or the node's `ledger_entry` when D9 has no answer, and the pure `mptPage` builds what `MptPage` draws. The MPT tab fills E11's seam (`mptAvailable`, the loader's `mpt` branch, `MptTable`).

**Tech Stack:** React Router 8.4 (framework mode) on Cloudflare Workers, React 19, TypeScript, `bignumber.js`, `ripple-address-codec` (Worker only), Vitest (`unit`, `components`, `worker`, `worker-off`), Playwright with axe.

**Spec:** `docs/superpowers/specs/2026-10-24-mpt-page-design.md` (cited as "spec §n" and "decision n"; "D9 §n" are the sections of the data API's `docs/superpowers/specs/2026-10-17-mpt-data-design.md`). The plan argues from the spec; executors read both.

## Global Constraints

- **Classes (spec §6):** the MPT page `minute` (indexed), `short` with `ttl: 60` (from the network); holders and transfers first page `minute`, behind a marker `MARKER_PAGE_CLASS`; the MPT tab E11's `minute` for every view (Rulings 1); `NoMptPage`, 404s and redirects `short`, the case redirect `immutable`; a transaction page with an unresolved MPT `short`; the image `slow`, from the network `short` 60 s. No page polls; no call asks for the failure hold.
- **Calls (spec §2.1):** `mpt(id)` `minute`; `mptHolders`, `mptTransfers` `minute`, behind a marker `MARKER_PAGE_CLASS`; `mptLookup(ids)` `slow`, IDs sorted and deduplicated, 1–100; `tokens({ kind: "mpt", … })` `minute`; `node.mptIssuance(id)` `live`.
- **No `mptLookup` call** while `MPT` is off, on a network without MPT, on a page with no issuance ID, or on the polling pages (home, ledger): their MPT amounts read in units.
- **The `MPT` switch:** appended last to `FEATURE_VARS` and `FEATURE_NAME` (`mpt`), `Env.MPT`, every block of `wrangler.jsonc` (top level `"on"`, `sandbox` and `production` `"off"`), `TOP_LEVEL_SWITCHES`, the cache-generation strings; the pre-deploy guard refuses `MPT` "on" unless `TOKENS` is "on".
- **Amounts:** MPT values are the ledger's integer units as text; `scaleUnits` (BigNumber) is the only place they are scaled, written with exactly `asset_scale` decimals through `formatAmount` (compact on the tab: `compactNumber`); a scale above 19 is shown unscaled with "units"; no float reaches a label. "HTF" in the spec's copy stands for the ticker, else "units".
- **Metadata is the issuer's, unchecked:** its text is React text; nothing of it reaches an attribute but an `href` that `safeLink` accepted; such a link has `target="_blank" rel="noopener noreferrer nofollow ugc"` and a visually hidden "(opens a new tab)"; the icon is a link, never an `<img>`.
- **Browser files** (pages, components and the domain modules they import: `mpt.ts`, `mpt-params.ts`, `mpt-link.ts`) import nothing at run time from `app/server`, `app/domain/describe`, `app/domain/parse` or `ripple-*`. `mptIdOf` and `mptIssuerOf` live in `app/domain/describe/helpers.ts` (Worker).
- **One URL per view:** anything but the canonical form is a 302 before any call (`short`; a case change `immutable`); paging is `trailPaging` (`?marker=M3&back=M2.M1`).
- **Names:** every loader passes what its page shows to `collectAddresses` and makes one `loadNames` call; a failed names call shows addresses and never fails the page (E9).
- **Words** (GLOSSARY): Issuance ID (not "MPT ID"), Asset scale (not "decimals"), Escrowed amount (not "locked amount"), Locked balance, Outstanding amount (not "supply"). Every sentence of the spec is copied exactly.
- **Commands:** `pnpm verify` (api:check, typecheck, test, build, check:bundle) exits 0 before every commit; `pnpm fixtures:check` after a fixture change; `pnpm test:e2e` after a task that touches a page. Narrow runs: `pnpm test <paths>`, `pnpm test --project worker test/worker/<file>`, `pnpm test --project worker-off test/worker/<file>`, `pnpm test --project components <paths>`.
- **Worker specs** share one Cache API per file: failure tests first, distinct IDs per test (`MPT_FIXTURE_IDS` has enough), and a test that overrides a key an earlier test failed moves the fake `Date` past `FAILURE_HOLD_SECONDS`.
- **Commits:** the repo's style (`feat(ui): …`, `test: …`, `docs: …`), a body saying why, the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never `--amend`, never `git add -A` or `git add .` (name the files; a generated fixture directory may be named), never touch `.claude/`, never push.
- **Bundle:** `mpt`, `mpt-holders`, `mpt-transfers` are lookup pages (150,000 B gzip with the manifest); the transaction and account pages stay under their budgets.

Plan decisions (the spec leaves them open):
- **Checks before any call, in this order** (spec §1.3): `MPT` off → 404 "We couldn't find the MPT pages on {network}"; Xahau or Xahau Testnet and 48 hex digits in any case → `NoMptPage` (the ID upper-cased); not 48 hex → 404; not upper case → 302 `immutable`. They apply to the three routes and the image (the image answers a plain 404 on Xahau). `checkMptRequest` (Task 10) is the one place.
- **More than 100 issuance IDs on a page:** the first 100 in sorted order are looked up; the rest stay in units.
- **The node mode's Locked tile:** `lsfMPTLocked` set → the outstanding amount with "Every balance is locked"; `can_lock` false → "0" with "The issuer cannot lock HTF"; otherwise "—" with "not in the index yet" (the issuance entry does not say which holders are locked).
- **The MPT tab's tags:** first page "MPTs · {network} · explorer", canonical `/{net}/tokens?kind=mpt`, indexable; searched or behind a marker, E11's `noindex, follow` without canonical.

## Review Focus

1. **The lookup fails or answers an ID bare.** Amounts read "2,500,000 units of MPT 0000012A…", the page is served, marked degraded (not stored) when the call failed, and a transaction page is `short`, never `immutable`, so units are not kept for a year. Tests: Task 7 `transaction-view.test.ts` `keeps the class only when every ID was answered with a scale`; `test/worker/transaction.spec.ts` `serves a failed lookup in units, short and not stored`.
2. **`MPT` off.** No `/v2/mpt` request anywhere, the routes and the image 404 without a call, `mptLink` null so amounts and references are text, `?kind=mpt` a 302, 48 hex digits the search help page. Tests: Task 10 `test/worker/mpt-off.spec.ts`; Task 7 `makes no lookup while MPT is off`; Task 12 `redirects kind=mpt while MPT is off`; Task 13 `search.test.ts` `48 hex digits with MPT off`.
3. **Xahau and Xahau Testnet.** `/xahau/mpt/{ID}` is `NoMptPage` (404, `short`, `noindex`, no call) with "Open it on XRPL"; the tab is disabled with "MPT isn't enabled on Xahau." and `?kind=mpt` a 302; search sends 48 hex digits to that page; no Xahau page asks for a lookup. Tests: Task 10 `mpt.spec.ts` `answers NoMptPage on Xahau in any case`; Task 12 `disables the tab on Xahau`; Task 13 `sends 48 hex digits to the Xahau page`.
4. **Metadata written to harm.** `javascript:`, `http:`, `ipfs:`, `data:` and protocol-relative URIs are text; a 50,000-character `additional_info` is cut to 2,000; hex that is not UTF-8 shows the hex only; nothing of the metadata appears in an attribute but an accepted `href`. Tests: Task 4 `mpt.test.ts` `safeLink`; Task 9 `mpt-view.test.ts` metadata states; Task 10 `MptPage.test.tsx` `puts no metadata text in an attribute but a safe href`.
5. **The index has no answer.** A new issuance, or one outside D9's coverage: the page from the node under "Not in the index yet, shown from the network", each card "Not in the index yet." on its 404; not on the node → 404; the node failing → 503; a destroyed issuance the index never saw → 404. Tests: Task 10 `mpt.spec.ts` `reads the node when the index has no answer` and its failure cases.

## Rulings

1. **The MPT tab behind a marker** is `minute`, E11's class for every view of `/{net}/tokens` (E11 §2.4, §6), not `MARKER_PAGE_CLASS` as E14 §6 says: the earlier spec wins, and one route keeps one rule.
