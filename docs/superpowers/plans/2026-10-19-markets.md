# Markets and Market Pair Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/{net}/markets` (every DEX pair of a period, from D2's one-call markets table) and `/{net}/markets/{base}/{counter}` (one pair: price, candles, trades, live order book, AMM pool, most active traders), behind the `MARKETS` switch, plus the pieces E4, E6 and E5 reuse.

**Architecture:** Two routes under `/:net`. Each loader validates and canonicalises the URL before any upstream call, then calls the data API (`data-api.ts`) and the node (`node-rpc.ts`) through the subrequest cache; pure view builders (`markets-view.ts`, `pair-view.ts`) turn the answers into page data whose every href and label is a string; `MarketsPage` and `MarketPairPage` draw it with E2's chart kit and never fetch. The markets page is class `minute` and never refreshes itself; the pair page is class `live-home` and follows the chain with E2's `createLiveOnScreen` and `keepLoaded`.

**Tech Stack:** React Router 8.4 (framework mode) on Cloudflare Workers, React 19, TypeScript, `bignumber.js`, `ripple-address-codec` 5, Vitest (`unit`, `components`, `worker`, E2's `worker-off`), Playwright with `@axe-core/playwright`, E2's chart kit (`app/ui/charts/`).

**Spec:** `docs/superpowers/specs/2026-10-19-markets-design.md` (the plan argues from the spec; executors read both). E2's spec `docs/superpowers/specs/2026-10-19-network-dashboard-design.md` §2 (kit) and §6 (shared mechanisms) defines what this plan consumes.

## Global Constraints

- **E2's pieces are used as they are, by name and file** (never by E2 task number): `tokenOf` / `fnv1a32` (`app/domain/fnv.ts`); `useHydrated` (the kit's `app/ui/charts/Plot.tsx`); `formatUtcDay` (`app/domain/format.ts`, which holds the month table); `useHolds` (`app/ui/use-hold.ts`); `byDeadline`, `CARD_DEADLINE_MS`, `TooLate` (`app/server/deadline.ts`); `mulberry32`, `seedOf` (`scripts/synthetic.ts`); `SubrequestOptions` (`app/server/cache-class.ts`: `{ holdFailure?: boolean }`, the fifth parameter of `SubrequestCache.json`); `PENDING_PATHS` (`app/server/pending-paths.ts`); `allSwitches` (`test/support/switches.ts`); `LiveRow` (`app/ui/components/LiveRow.tsx`); `SegmentedLinks` and its `SegmentLink = { label; href; current }` (`app/ui/components/SegmentedLinks.tsx`); `CursorSlot` (`app/ui/charts/CursorSlot.tsx`, E2's lazy-cursor fallback, present only if E2 applied it). A kit component or shared file gains a prop or an export only as a growth step a task names, with a default that keeps E2's behaviour; no kit file is forked and nothing is copied.
- **One asset form** (`app/domain/asset.ts`): URLs carry `assetText`, the API is sent `apiAssetText`, the node the currency as the ledger holds it. **One orientation**: every display of a pair uses `naturalOrientation`; `canonicalPair` is for talking to the API only.
- **The pages never fetch and get strings.** View builders put every href and label in the page data. `app/server/*`, `app/domain/asset.ts`, `app/domain/market-pair.ts` and `ripple-*` are never value-imported by `MarketsPage.tsx`, `MarketPairPage.tsx`, `LiveStateNotice.tsx`, `use-retry.ts` or `app/server/meta.ts` (`test/unit/markets-bundle.test.ts`). The browser never gets a node or API answer.
- **Exact numbers.** View builders compute with `bignumber.js` at `DECIMAL_PLACES` 80; no float reaches a string. Prices: `formatPrice` (8 significant digits, half up, trailing zeros dropped, grouped, never in exponent form). Table cells of amounts: `formatAmount`. Summaries (tiles, book sizes, pool reserves, trader tips): E2's `compactNumber`. A minus sign is U+2212.
- **Switches** (E2 §6.1): `MARKETS` is page-level: off, both routes and every view answer the not-found page "We couldn't find the markets pages on XRPL" (a 404 of class `short`) before any call, and the header's Markets is the "soon" label. `"on"` at the top level of `wrangler.jsonc` and in `TOP_LEVEL_SWITCHES` (development, tests); `"off"` in `staging` and `production`. `AMM_DATA` (E2's) gates the AMM parts (Trades filter, Via column, AMM share tile and column, pool card share, the intro's "swaps against AMM pools" words) on XRPL only; on Xahau `hasAmm` is false whatever the switch, and D2's `"0.0000"` there is ignored. Nothing asks the API whether it has AMM data.
- **Cache classes.** New class `minute`: 60 s fresh, 30 s stale, browser `max-age=0, must-revalidate`; a subrequest of class `minute` is kept 60 s (its edge TTL), with no TTL constant of its own. Markets page and its `.data` URL: `minute`. Pair page and its `.data` URL: `live-home`. A pair page behind a marker: `MARKER_PAGE_CLASS` (`slow`). Every 404: `short`, `noindex`, `cached({ notFound }, "short", { status: 404 })`. Redirects are 302: `immutable` when only the path changed, `short` when the query changed (with or without the path).
- **The pair page's calls** (spec §3.3, the table is the contract): #1 `last_validated` and #2 the trades kept `HOME_CALL_TTL_SECONDS` (2 s); #6 and #7 `book_offers` kept 2 s; #3, #8, #9, #10 `live` (5 s); #4 `live` for 15 m and 1 h, `minute` for 4 h, 1 d, 1 w; #5 `minute`. Every call of the pair page passes `holdFailure: true`, the node's included. Card calls and the chains go through `byDeadline(work, start + CARD_DEADLINE_MS)` from the start of the loader (a `TooLate` gives the reason "took too long"); the node's own limit is 3 s. `Promise.allSettled`, and an outage is thrown only after everything has settled. Nothing is streamed or deferred.
- **Validation first.** Anything malformed is a 404 with no upstream call; redirects are made before any call too.
- **Degraded, not stored.** A failed card is logged (`logProblem`) and marks the answer degraded (`markDegraded`). An absent pool and the parts the switches leave out are answers, not failures.
- **Indexing.** Indexable: the markets page's default view, and a pair's default view in its natural orientation with at least one trade. Everything else is `noindex, follow` with no canonical link and no `og:*`. No Open Graph image for either page; no numbers in a description.
- **Selectors are E2's `SegmentedLinks`** (`aria-current="true"` on the current one, 32 px to look at, a 44 px target), hrefs from `marketsHref`/`marketHref` in the view builders, client navigations with `preventScrollReset`. No inline copy of the control.

- **A market that does not exist versus an upstream that failed**: no trade and an empty book; no trade and a failing node; a Trades filter whose list is empty while the pair has other trades; a refused marker.   | Input (after splitting on the one separator `.`, `+`, space or `\|`) | Asset |
  |---|---|
  | no separator, the network's native code in any case | `{ currency: native }`; anything else alone is `null` |
  | more than one separator | `null` |
  | issuer that is not `isValidClassicAddress` | `null` |
  | code equal to the native code in any case, with an issuer | `null` |
  | 3 characters from `A–Z a–z 0–9 ? ! @ # $ % ^ & * < > ( ) { } [ ]` | that code upper-cased (the canonical case rule) |
  | 40 hex digits, all zero | `null` |
  | 40 hex digits, bytes 0–11 and 15–19 zero and bytes 12–14 a standard code | that code upper-cased (and `null` if it is the native code) |
  | 40 hex digits otherwise | the hex upper-cased |
  | 4 to 20 characters from `0x21–0x7E` | the text's bytes, left-aligned and zero-padded to 40 hex digits, upper-cased |
  | anything else | `null` |
